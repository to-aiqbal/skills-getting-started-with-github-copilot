## Backend Tests

Backend API tests are located under [tests/backend](tests/backend) and use `pytest` with the Arrange-Act-Assert (AAA) pattern.

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run all tests:

```bash
pytest -q
```

3. Run only backend API tests:

```bash
pytest -q tests/backend
```
